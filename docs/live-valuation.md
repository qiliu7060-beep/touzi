# 公网 PE/PB 历史分位卖出提醒

网站持仓提醒每轮取得腾讯报价后，分别重新判断 PE/PB 自身五年历史分位卖出条件。个人持仓、成本和数量仍只存在浏览器，未写入公共导出数据。

## 历史池与边界

发布器只读取评分流程已经抓取的百度 `stock_zh_valuation_baidu`「近五年」PE(TTM)/PB 缓存，不发起额外历史请求，也不使用行业分位、市场截面或价格推算值。缺失、超过配置 TTL、格式异常的缓存不生成有效阈值。读取失败不阻断整站发布。

与现有评分一致：日期去重、去除空值并按 `as_of` 截断；原序列超过20项，且至少5个正有限样本。这里的“五年”沿用数据接口的时间窗口，未新增“必须上市满五年”的要求。样本不足会标记未知，不以替代指标填充。

`percentile_of(v, pool)` 为 `count(pool < v) / n`；`score_valuation` 将结果保留四位小数后交给 `evaluate_sell`。发布器寻找最小满足 `round(k/n, 4) >= 配置分位` 的整数 k，并导出未经舍入的第 k 个有序样本。浏览器使用严格 `v > boundary`，不使用 `>=`。这同时保留重复样本、非整数百分比和评分舍入边界；不改变任何策略参数。

## 报价与未知状态

实时估值要求代码匹配、正有限现价、正有限 PE/PB，以及合法的北京时间报价时间。交易时段最多接受10分钟延迟；午休接受当日上午尾盘数据；收盘后和周末接受最近工作日收盘数据。过期、未来、日期无效、异常时间、缺失或非正估值均不能证明该分位规则未触发。没有节假日日历时保守显示无法判断，公共快照继续保留。历史池发布日期超过7天也不再用于实时判断。

单项成功后只替换对应的分位快照条件；其他公共风险条件保留。单项失败则明确提示该项实时判断无法完成，并保留仍有效的公共快照风险。PE 缺失不阻止有效 PB 触发；数据不足也不阻止个人止损/止盈或其他已确认风险提醒。

只有这两条历史分位条件随 PE/PB 报价重新判断。财务、宏观、总分和其他公共条件仍依赖发布快照。历史池仍由现有 GitHub Actions 定时任务更新；浏览器复用原有15秒行情请求，没有新增接口请求。原有新发布检查继续负责取得新一轮历史池与公共评分。
