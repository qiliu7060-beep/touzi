## 成交和比较口径

- 信号日期采用季度实际最后一个市场交易日，避免 `resample` 生成周末/节假日日期。只用已完成季度，并要求有后续市场交易日。
- 当日收盘后形成信号，订单只能在严格晚于信号日的市场交易日收盘成交。当前信号时点按等权目标和预估实际换手费确定目标数量，下一日价格跳空会使实际权重发生偏离；不会事后按未来价格回改信号。
- 逐日记账，先卖后买，不允许负现金或借入股票。手续费按实际成交金额单边扣除，首次买入只有买入费；相同股票因权重漂移再平衡也收费，未交易不收费。
- 成交量为零、标记停牌或方向性限制时不能成交；支持调用方提供 `tradable`、`buy_blocked`、`sell_blocked`。对当日目标、未到期订单或已有持仓，无法解释的价格缺行、无效价格或未知/无效成交量必须拒算，不能当作停牌。只有逐日 `security_status='suspended'` 且 `status_source` 指向已核验原始档案时，允许缺少当日价格/成交量；无当日有效价时沿用已有价格并记录 `suspended_mark`，无历史估值则拒算。缺失交易限制标志不代表已核验涨跌停/流动性，因此结果声明不包含无标记的涨跌停约束。
- 买入不能成交则保留现金；卖出不能成交则保留持仓。订单超过 `max_wait_days`（默认15个自然日）取消，新信号在该收盘后替换未成交订单。不会剔除失败股票后把收益重新均分给成功股票。
- 沪深300账户同样初始持现金，在首个信号之后的下一市场交易日收盘买入，后续连续持有，避免基准提前一个收盘价入场。基准使用价格指数且不扣成本，策略使用调用方核验的统一复权价格指数；两者未必是相同股息再投资口径，不能把差异都归因于选股能力。
- `q_ends[:-1]` 是实际调仓信号，最后季度末 `q_ends[-1]` 仅作为统一估值边界，不生成新信号，也不额外计入次一交易日收益。末端不伪造成交清仓，不扣未发生的卖出费。有证据的停牌持仓沿用最近价格估值，风险可能低估。输出逐日净值、实际交易、逾期/未成交事件，指标以未四舍五入的净值计算，初始净值1纳入回撤。

## 可复现数据接入契约

`backtest_portfolio(..., historical_universes=..., archived_raws=..., benchmark=...)` 可离线运行。所有日期须为无时区的中国本地交易日期/时间。所有验证标志由独立核验过原始来源、历史版本与覆盖范围的导入者填写，不是代码自动认证。

- `historical_universes`: `{实际季度末交易日: DataFrame}`，每期原始存档包括 `code/name/industry` 及按当时信息确定的完整候选池；包含退市/暂停上市股票及当时市值、ST、上市年限等筛选证据。缺一期报错，不能用较近/当前池填补。历史档案路径不额外执行 `limit` 当前市值截断。
- `archived_raws`: `{code: raw}`，代码为保留前导零的字符串。`fin` 含 `report_date/available_at/is_annual` 及既有质量指标列；`fin_vintage_verified=True` 表示已核验每行所属原始版本。更正版本用其自身新披露日期，不能给现今更正值贴首次公告日。
- `available_at` 不是报告期，也不是抓取时间。本实现保守地让所有公告在次日才可用，包括有精确时刻的公告；牺牲少量及时性，避免把只有日期的盘后公告按当日收盘信号使用。披露时间、报告期/除息日均解析为日期时间后排序及去重，日期字符串是否补零不影响版本选择。同一报告期/除息日、同一披露时刻的完全重复行可去重，内容冲突则拒绝；多个独立分红事件若共用除息日，导入者须先按当时可见版本汇总并保留事件明细证据。
- `pe_hist/pb_hist`: 唯一的 DatetimeIndex 日序列，`valuation_vintage_verified=True` 表示原始历史估值而非利用后来的财报重建。无可靠原始记录时保持缺失。
- `div`: `available_at/ex_date/dps`（每股派息）。`div_vintage_verified=True` 且 `div_history_complete=True` 表示已核验完整公司历史及当时已实施事件；完整空表可表示确无分红，未核验的空表表示未知。
- `bond_hist`: DatetimeIndex 收益率百分数日序列，`bond_vintage_verified=True`；缺失允许继续，但会报告未使用利差项。
- `price_hist`: 未复权 `close`，`signal_price_basis='unadjusted'`。`return_price_hist`: 同一基准且公司行动处理一致的复权 `close/volume`（可含交易限制列）；`return_price_basis_verified=True`。每个有敞口、订单或新目标的市场交易日都须有记录。正常行需有限正收盘价及有限非负成交量；有证据的停牌行可以没有价格/成交量，但必须填写 `security_status='suspended'` 与非空 `status_source`。若提供状态列，正常行填 `trading`，未知值不放行。缺行不能自动推断停牌；退市或其他未支持的状态拒算，直至有核验过的处置路径，不能无限延用退市前价格。尚未选中和已完全退出的证券不强求覆盖其余交易日。后者仅用于收益价格指数和成交数量模型，不直接冒充原始人民币股价/真实股数。导入者须核验两套价格的日期、公司行动及一致性。
- `benchmark`: 日期索引 `close`，完整市场交易日历。缺失、重复或非正基准收盘价拒绝运行。须保留数据来源、下载日期、文件哈希、单位及版本清单，并将原始档案冻结后才能复算/引用结果。

`HistoricalDataError.audit` 包含 `signal_date/code/eligible/missing/bond_missing/universe`（评分异常时保留异常类别）。收益数据不足时不返回部分可用季度拼凑出的净值；调用方可捕获异常并导出审计表。不得把没有产生新结果解释为策略收益为0。

价格/证券状态拒算时，异常审计还追加 `date/code/missing/stage='return_prices'`，保留此前评分审计。`scripts/run_all.py` 仅捕获预期的 `HistoricalDataError`，保存 `backtest_b_audit.csv` 和 `backtest_b_status.json`，标记 B 为 `not_computed`，继续 C 和报告步骤；其他程序错误仍抛出。总结果文件将 B 标为未计算，不含收益。`--reuse-backtest` 只接受总结果与独立状态文件均为 `computed` 且 `history_contract='pit-v2'` 的 B 缓存，防止旧 CSV 或最近一次拒算前的结果被重新展示为本次收益。旧文件不被当作有效结果，也不被删除。
