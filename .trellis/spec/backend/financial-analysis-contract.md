# 企业财务分析契约

## 范围与权威

新增损益表、债务股权或资本开支分析，及其质量分、公开模型和财务提醒时读取本文。Python 是计算权威；Worker 消费固定质量分和完整公共 Check，不另行抓取财报推测分数。新增能力标识 `touzi-live-v2`；消费者兼容 v1 时必须说明旧版缺少财务分析。

## 口径

- 债务股权比率 = 总负债 / 合并股东权益（含少数股东权益）。不得直接使用资产负债率，也不得换成有息债务分子。
- 资本开支 = 购建固定资产、无形资产和其他长期资产支付的现金；五年比例 = 最近应披露完整财年起连续五年累计资本开支 / 同期合并净利润。
- 不以归母净利润替换合并净利润；扣非归母净利润单独命名。不把净利润与经营现金流混为一项。
- 同一计算窗口匹配币种、单位、合并类型和来源。缺失、旧数据、行业不适用和已确认财务异常必须区分。
- 年报使用 12-31 完整年度数据，不累计四个季报的年内累计数，不跳过缺年或亏损年拼五年。

## 分数和提醒

具体权重及端点集中在配置。质量分采用 ROE25%、现金流20%、债务股权20%、稳定性20%、资本开支15%；总分质量模块保持30%。新债务项替代旧质量负债项，不重复计分；保留旧负债字段供展示及独立筛选。

原始精度严格比较：债务 <0.8 为优良，资本开支比例 <25% 为达标。等于边界不贴优良标签，但连续评分曲线端点仍可为100分，标签与分数不能互相推导。

新增五个公开 Check：`sell_debt_equity`、`sell_equity_nonpositive`、`sell_capex_to_profit`、`sell_annual_loss`、`sell_cumulative_loss`。直接等级为预警，不能改成清仓/减仓；总分变化仍可触发现有总分规则。每项保留 value、threshold、hit、known、level、note；未知不是确认未触发。

银行、保险、证券的债务和资本开支项不机械套阈值；保留原房地产负债豁免。缺失/不适用项不补零，在可用项归一化并展示覆盖率。有效的非正权益是异常事实，累计净利润非正是资本开支比例无法计算，不能把二者统称取数失败。

新浪49板块的“金融行业”属于上述金融豁免，不能只匹配细分行业名称。行业为空时无法确认标准适用性：保留原始金额和数值，将债务及资本开支指标标为 missing，优良标签为 null，两项不计分、不触发通用阈值预警；最新年度/累计净利润亏损仍按有效财报独立核验。不得凭股票简称猜测细分行业。

## 时间、公开和运行边界

报告期、源更新时间和实际获取时间分别保存；缓存命中不能把 fetched_at 重写为当前时刻。过期财务输入不能触发新的确定性财务预警；有效年报本身较旧不等于抓取失败，判断新鲜度需结合应披露年度及真实获取状态。

财务数据由既有数据任务检查更新，行情轮询不会让新财报瞬间可用。公开资产只含企业数据，不得包含私人持仓、成本或身份。网页仍遵守现有可见时运行、提醒去重和恢复后重触发约束。

## 验证

适配器启用前核查实际原始响应和公开年报金额、单位、合并范围；不能只凭文档字段名断言口径。测试必须覆盖连续五年、年内累计去重、年报更正、亏损、非正权益、严格阈值、舍入、缺失与行业豁免；跨语言验证完整 Check。生产者和消费者白名单/模型版本及镜像副本同时维护，不手改 dist。

## 可执行接口与错误矩阵

- `touzi/data/financial.py::normalize_reports(code, source, reports, fetched_at)` → 单表 DataFrame；source 为 fzb/lrb/llb，只接受 CNY 和合并期末。
- `fetch_financial_statements(code, cache, ttl_days=1)` → 三表字典。固定新浪公开接口，单响应上限4MiB、8秒超时、三表最多3线程，分别缓存并保留真实 fetched_at；源失败可回退旧缓存，无缓存返回该表空 DataFrame。
- `analyze_financials(tables, industry="", as_of=None, ttl_days=1)` → financial_analysis。窗口包含固定连续5年，4月30日当日之前截止前年，5月1日起截止上年。
- `score_quality` 为分析追加 quality：coverage、missing、weights、sub_scores、contributions；贡献基于未舍入子分计算，旧 detail.sub_scores 可保持展示舍入。
- `financial_analysis` 包含 status、source、currency、unit、statement_scope、fetched_at、source_updated_at、window、years、metrics、loss_years、notes、quality。指标名为 debt_equity、capex_to_profit、annual_net_profit、cumulative_net_profit。

| 输入/错误 | 输出/行为 |
| --- | --- |
| 币种或报表类型不符 | normalize_reports 拒绝；不偷换合并/母公司口径 |
| 缺年度、缺金额、负资本开支 | 对应累计比例 missing，不补零 |
| 累计净利润非正 | capex比例 invalid/value=null；独立累计亏损预警仍可核验 |
| 权益非正 | debt比例 invalid/value=null，权益原值保留，适用行业计0分并预警 |
| 超过24小时的 fetched_at 或未来超过1分钟 | 对应指标 stale，不参与新分和确定性预警 |
| 债务最新报告期早于窗口截止年年末 | debt stale，不用刚重新抓取的旧年报伪装最新负债 |
| v2 已知预警携带生成时已陈旧的 fetched_at | Worker消费者拒绝；仅经验证收盘基线的休市复用可在真实生成时刻核验获取状态，不改写fetched_at、不新发确定性交易提醒 |
| 扣非归母净利润无可靠同源字段 | null，明确提示缺失，不推算 |

## 正常、边界及错误示例

正常：五年每年净利润100、资本开支20，累计比率20%；债务80/权益100=0.8，债务优良标签为false、债务子分100，且债务预警命中。

边界：某年亏损但五年总利润为正，保留该年参与累计并标记亏损；总利润非正则比例无法判断，不能显示“负比例优良”。金融及地产豁免按上述规则单独展示。

错误：将请求当天00:00当作当前时间核验当天20:00获取的财报，会把有效新数据判为未来。实时 `Screener.score_one` 必须用实际北京时间做财务获取新鲜度核验；回测不使用当前更正三表。确定性测试显式固定财务 now。

## 必测断言和反例

`tests/test_financial_analysis.py` 覆盖严格阈值、连续曲线、权重、缺年不滑窗、季度累计不相加、更正覆盖、亏损、权益非正、旧缓存、未来时间、行业豁免、未知行业及合并字段选择。`tests/test_live_model.py` 包含80组Python/Worker逐字段对照，含新增财务状态、大类金融行业及缺失行业。`webapp/scripts/test-financial-ui.mjs` 检查亿元单位、缺失、舍入、来源、贡献、选择保留、以规则ID去重及恢复后重触发。

错误：从归母权益字段取分母，或先把比率舍入成0.80再判优良，或把更新抓取时间写成财报披露日。

正确：从已与正式年报核对的 RIGHAGGR/TOTSHAREQUI 取合并权益，原值比较阈值；报告期、source_updated_at、fetched_at 分别保存。

## 覆盖统计与缺项归因

`touzi/financial_coverage.py`和Worker公共聚合镜像分别统计报告状态、四项指标状态、质量权重覆盖和扣非展示字段缺失数；分母固定为当前模型股票数/五年期望单元格。报告`ok`不等于表格全字段完整；行情覆盖不等于财报覆盖。Python/JS用同一输入做聚合对照。

页面需区分行业归属未知、应披露年度缺失、上游字段未覆盖、行业豁免、有效异常及过期/失败。2026-10-23样本中的99项partial有98项来自行业为空，另1项缺固定窗口年度，不能笼统宣称99只抓取失败。具体数量由每次模型实际聚合，禁止硬编码样本数量。

现有适配未建立扣非归母净利润可靠映射；NETPROFIT、归母净利润、持续经营净利润不能替代扣非。只有实际响应和合并/单位/期别证据充分才增加映射；无证据保持null并显示来源未覆盖。未知行业不能凭名称猜行业以凑覆盖率。
